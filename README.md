# Balance

Balance is accounting software for individuals and businesses. It combines a
controlled double-entry ledger with an AI assistant that prepares reviewable
proposals without bypassing accounting rules.

## Development

The supported local setup uses Docker:

```sh
docker compose up --build
```

Open [http://localhost:8080](http://localhost:8080). See [DOCKER.md](DOCKER.md)
for configuration, lifecycle, production-image validation, and troubleshooting.
